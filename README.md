# ToDo List на Go

Учебный проект — консольное приложение для управления списком задач (ToDo List), разработанное на языке Go.

## Цель проекта

Основная цель проекта — закрепить и применить на практике материал, изученный в рамках курса по основам Go.

При разработке приоритет отдавался повторению изученных возможностей языка, а не следованию всем современным практикам проектирования и разработки программного обеспечения. Поэтому некоторые решения в коде могут отличаться от тех, которые были бы выбраны при разработке полноценного production-приложения.

При рассмотрении и критике исходного кода прошу учитывать учебный характер проекта и его основную цель.

## Возможности

Приложение предоставляет следующие возможности:

- **Добавление задач**
  - Заголовок задачи должен состоять из одного слова.
  - Основной текст задачи может содержать произвольное количество слов.
  - Для каждой задачи сохраняется время создания.
  - Каждая задача имеет статус выполнения.
  - Для выполненных задач сохраняется время завершения.

- **Просмотр задач**
  - Получение полного списка добавленных задач.

- **Управление выполнением**
  - Отметка задачи как выполненной по её заголовку.
  - Сохранение статуса и времени выполнения задачи.

- **Удаление задач**
  - Удаление задачи по её заголовку.

- **Журнал событий**
  - Запись пользовательского ввода.
  - Сохранение времени возникновения каждого события.
  - Сохранение текста ошибки, если обработка команды завершилась неудачно.
  - Пустое описание события, если при обработке команды ошибок не возникло.
  - Просмотр полного списка событий за время работы программы.

## Доступные команды

| Команда | Описание |
|---|---|
| `help` | Вывести список доступных команд и их формат |
| `add <название> <текст>` | Добавить новую задачу |
| `list` | Показать все задачи |
| `del <название>` | Удалить задачу по заголовку |
| `done <название>` | Отметить задачу как выполненную |
| `events` | Показать журнал событий |
| `exit` | Завершить работу программы |

### Примеры использования

```text
add Учёба Изучить основы языка Go
list
done Учёба
del Учёба
events
help
exit
```

Заголовок задачи должен состоять из одного слова. Текст задачи может содержать несколько слов.

## Технические требования задания

В рамках исходного учебного задания предусматривалось:

- Реализовать взаимодействие с пользователем через консольный ввод.
- Организовать проект в виде Go-модуля.
- Использовать как минимум одну стороннюю библиотеку.
- Вынести часть функциональности в отдельные пакеты помимо `main`.
- По возможности применить изученные в первой части курса возможности языка Go.

## Статус проекта

Проект предназначен для обучения и практики работы с Go. Его архитектура и реализация отражают задачи и ограничения учебного задания.
